# KPanel v0.21.0 验收记录

日期：2026-07-28

## 变更范围

- 公网 IPv6 可用时，DNS 预设自动补充同服务商的 2 个 IPv6 解析地址。
- kejilion.sh 应用配置统一使用 `docker.io/kjlion/kejilion-panel:latest`。
- 左侧导航将“体检”移动到 Docker 下方。
- 体检工作台压缩命令区并扩大终端；Docker 容器页操作按钮保持同排。
- `k web del` 删除站点成功、数据库删除失败时返回部分成功和数据库残留警告。

## 自动化验收

- `go test ./...`：通过。
- `go vet ./...`：通过。
- Web Vitest：6 个测试文件、35 项测试通过。
- Web TypeScript 检查与生产构建：通过。
- Linux `amd64` / `arm64` 三个二进制交叉构建：通过。
- Shell 语法、生态策略与安装安全测试：通过。
- kejilion.sh 应用安装、更新、卸载生命周期：通过。
- `kejilion-panel:verify-0.21.0` 生产镜像构建及 `image-e2e.sh`：通过。

## 界面验收

- 1920×1080：体检右侧终端有效高度 660px，左侧命令区 310px，操作按钮可见。
- 680×900：体检终端保留 420px 高度并切换为上下布局。
- Docker 容器页桌面端两个操作按钮同一行；680px 窄屏下使用等宽双列，仍保持同排。
- 导航顺序确认：概览、网站、应用市场、Docker、体检、活动记录、设置。

## 风险与回滚

- 数据库删除失败不会再阻止站点删除结果落账，但数据库可能残留；面板会明确提示管理员手动核对。
- `latest` 会随正式发布更新；版本回滚时应同时回滚 Docker Hub `latest` 指向和应用目录配置。
- 回滚代码使用发布前标签 `v0.20.8`，数据库与配置格式未发生迁移。
