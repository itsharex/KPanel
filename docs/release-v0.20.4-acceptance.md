# KPanel v0.20.4 回归修复与发布验收

## 本次问题闭环

| 用户反馈 | 修复链路 | 自动验收 |
| --- | --- | --- |
| WordPress 错进 `k web` 菜单 | 后台 PTY 直接执行 `k wp <域名>` | 固定参数与脚本协议测试 |
| IP+端口反代失败 | 后台 PTY 直接执行 `k fd <域名> <目标> <端口>` | 参数、协议与产物对账测试 |
| 成品站建站窗口无法关闭 | 任务持久化，窗口可转入后台，并可从网站页恢复终端 | API 列表、轮询与前端构建 |
| 完整删除提示版本不可用 | 缺少资源版本时校验站点身份并调用 `k web del <域名>` | 域名不匹配拒绝与产物删除测试 |
| 体检脚本依赖确认时报 `Invalid input` | 固定来源先下载后在 PTY 中执行，不再使用 `curl \| bash` | 脚本烟雾测试 |
| 体检终端不能输入或显示颜色 | 独立 FIFO 输入、`xterm-256color`、原始 ANSI 分块传输 | ANSI 原样传输与输入 CSRF 测试 |

## 实机复核命令

1. 在网站页分别创建 WordPress、IP+端口反代和一个成品站，关闭窗口后重新打开任务终端。
2. 删除测试站点，确认配置、目录、证书和同名数据库按 `k web del` 语义处理。
3. 在体检页执行 IP 质量体检；依赖确认时输入选项，并确认终端颜色和历史输出均可恢复。
