# KPanel v0.30.0 发布验收

## 范围

- 左侧导航在 Docker 与“体检”之间增加轻量文件工作台。
- 支持 `/home` 日常文件浏览、搜索、排序、上传、下载、新建目录、重命名、复制、
  移动、回收站、权限修改、批量选择和右键菜单。
- 增加轻量代码编辑器，以及图片、PDF、音频和视频查看器。
- 文件上传、下载和复制采用固定缓冲流式处理，不把完整文件载入 Panel 或 Agent 内存。

## 安全与兼容结论

- 文件根固定为 `/home`，所有文件系统操作通过 Go `os.Root` 根句柄执行。
- KPanel 数据目录、其祖先目录、内部临时文件和回收站不可通过文件页面修改。
- 拒绝路径穿越、符号链接逃逸、活动 HTML/SVG、任意 Shell 和任意宿主机路径。
- 写操作继续使用 Session、Origin、CSRF、固定动作枚举、资源版本和审计记录。
- 文本编辑限制为 2 MiB，单次上传限制为 512 MiB，复制限制为 10,000 项或 10 GiB。
- 本次不修改 `kejilion.sh`，原应用、建站、Docker、体检和集群协议保持兼容。
