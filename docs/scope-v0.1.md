# v0.1 首版范围与验收

## 页面

- 首次初始化与登录
- 概览
- 网站
- Docker
- 变更记录
- 审计
- 设置

## 必须完成

### 认证

- 无默认密码，一次性初始化凭据使用后失效。
- Argon2id 密码哈希。
- 服务端随机 Session 和 `HttpOnly` Cookie。
- CSRF 与 Origin 校验。
- 登录限速、失败审计和会话注销。

### 主机状态

- CPU、内存、负载、磁盘、网络、运行时间和系统版本。
- Agent 状态和只读降级。
- Nginx、MySQL、PHP、Docker 服务摘要。

### 网站

- 发现现有静态站、反向代理站、证书和不明确资源。
- 展示来源、真实产物、资源版本和最后对账时间。
- 固定模板静态站、反向代理站创建和安全更新。
- 配置计划、`nginx -t`、原子替换、reload 和回滚。
- 首版不删除网站、目录、数据库或证书。

### Docker

- 容器、镜像、网络、卷和 Compose 信息。
- 有界日志与一次性资源统计。
- 安全识别容器的启动、停止和重启。
- 外部或危险容器只读。

### 任务和审计

- 网站与容器写操作返回类型化结果。
- 以持久化审计意图和结果生成管理变更记录。
- 保存结构化错误和脱敏事件。
- 资源发现保留 Web、脚本发现和外部来源标签；Web 管理操作写入审计。

## 发布门槛

- `go test ./...`、前端类型检查、构建和单元测试通过。
- Linux amd64/arm64 二进制成功构建。
- Docker 镜像以非 root 用户运行并通过健康检查。
- 初始化、登录、注销、会话失效 E2E 通过。
- 现有脚本站点和容器只读发现测试通过。
- Web 创建站点后，产物符合 `kejilion.sh` 的路径与命名约定。
- 无效配置不 reload，原文件哈希保持不变。
- 外部并发修改不会被覆盖。
- Agent 离线或布局不兼容时全站只读。
- API、日志和审计不包含私钥、数据库密码、Cookie 或 Docker 环境变量。
